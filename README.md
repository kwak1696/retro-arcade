# Retro Arcade

[Play](https://kwak1696.github.io/retro-arcade/)

| Game | Edition | Status |
|---|---|---|
| NOM | Overseas Java | Playable |
| NOM 2 – Free Runner | Overseas Java | Playable |
| NOM 3 | Korean WIPI | JavaScript beta |
| MiniGame Paradise 1 | Korean WIPI | JavaScript beta |
| MiniGame Paradise 2 | Korean WIPI | JavaScript beta |
| MiniGame Paradise 3 | Korean WIPI | JavaScript beta |

Choose a game and press Start. Touch/click the display or press Enter/Space for
OK/action; arrow keys navigate. In fullscreen, controls use spare letterbox space
when there is enough room for touch targets. Progress is stored in this browser.

The four WIPI titles are translated to JavaScript before publishing. No JVM, ARM
instruction interpreter, or Wasm runtime is downloaded. WIPI sound is rendered from the original scores/samples before deployment; FM
timbres are approximate. Three MiniGame Paradise 1 clips still render silent.
Vibration and retired handset/carrier services are currently unavailable. These ports are beta;
all later stages and game paths have not been exhaustively tested.
